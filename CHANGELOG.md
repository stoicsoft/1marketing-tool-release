# Changelog

All notable public release changes for 1MarketingTool are tracked here.

## 0.1.0 - Private Beta Track

Initial release track for the desktop app.

### Included

- Local-first workspace and product setup
- Content Machine campaign generation and local content library
- Brand voice, product profile, source context, screenshots, and supporting files
- Design Studio for local visual asset generation
- Asset library with reusable collections
- Content calendar, channel setup, publish history, and local auto-publish workflow
- Unified performance dashboard for search, analytics, rank, backlinks, SEO health, and PageSpeed workflows
- Keyword Explorer, keyword clustering, saved keywords, content briefs, and SERP analysis
- AI Visibility tracking, saved trackers, and Prompt Explorer
- Site Audit, Google Request Index, and IndexNow workflows
- Directory Submit automation and submission status tracking
- OS keychain credential storage and local SQLite data storage

### Platforms

- macOS Apple Silicon and Intel
- Windows x64

Linux packaging is on the roadmap.
